💰 FinanceFlow

Take Control of Your Money, Build Better Financial Habits.

FinanceFlow is a personal finance management application designed to help users manage their finances more easily. Track income, monitor expenses, manage savings goals, and visualize your financial condition through an interactive dashboard.

🚀 Features

Authentication – Secure user authentication.

Dashboard – View financial summaries and current balance.

Income Management – Record and manage income transactions.

Expense Management – Track and manage daily expenses.

Transaction History – View, filter, and manage transaction records.

Categories – Organize transactions by category.

Initial Balance – Set your starting account balance.

Savings Goals – Create and monitor personal savings targets.

Financial Charts – Visualize income and expenses with interactive charts.

Responsive UI – Accessible through different screen sizes.

🛠️ Tech Stack

Technology

Usage

PHP - Backend Programming

Laravel - Backend Framework

MySQL - Database

Blade - Frontend Templating

HTML & CSS - User Interface
